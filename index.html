INSTALL

APK 설치는 1분이면 끝나요

NEON HUB는 플레이스토어가 아닌 이 공식 홈페이지에서만 배포해요. 다른 사이트에서 받은 파일은 설치하지 마세요.

  1. APK 파일 받기이 페이지의 APK 다운로드 버튼을 눌러 파일을 저장해요.
  2. 설치 허용하기처음 한 번만 필요해요. 갤럭시 기준 설정 → 애플리케이션 → 특별한 접근 → 출처를 알 수 없는 앱 설치에서 사용하는 브라우저를 허용해요.
  3. 파일 열어 설치다운로드 알림이나 내 파일 → 다운로드에서 APK를 눌러 설치해요.
  4. 실행 후 닉네임 정하기설치가 끝나면 허용했던 설정은 다시 꺼두는 걸 추천해요.

FAQ

자주 묻는 질문

이벤트 일정은 어디서 가져오나요?

게임사 공식 발표, 로블록스 게임 페이지의 공식 이벤트 목록, 그리고 매주 반복되는 업데이트 패턴을 확인해서 넣어요. 공식으로 발표된 일정은 '공식', 패턴이나 추정으로 계산한 일정은 '예상'으로 따로 표시하고, 이벤트마다 출처를 달아요.

예상 일정이 틀리면 어떻게 되나요?

예상 일정은 확정이 아니라서 실제와 다를 수 있어요. 공식 공지가 나오면 일정을 고치고, 앱은 다시 설치하지 않아도 자동으로 새 일정을 받아요.

플레이스토어에는 왜 없나요?

지금은 이 공식 홈페이지에서 APK로만 배포하고 있어요. 다른 사이트나 메신저로 받은 파일은 바뀌었을 수 있으니 설치하지 마세요.

APK 설치, 안전한가요?

이 홈페이지에서 받은 파일만 설치하고, 위에 공개된 SHA-256 값과 비교해 보세요. 설치 후에는 '출처를 알 수 없는 앱 설치' 허용을 다시 끄는 걸 추천해요.

활성화 코드를 잃어버렸어요.

결제할 때 입력한 이메일로 코드가 다시 발송돼요. 메일이 안 오면 아래 문의처로 결제 일시와 이메일을 보내 주세요.

환불할 수 있나요?

코드를 앱에 등록하기 전이라면 결제 후 7일 안에 환불을 요청할 수 있어요. 등록한 뒤에는 이미 적용된 디지털 상품이라 환불이 어려워요.

게임사에서 만든 공식 앱인가요?

아니에요. NEON HUB는 팬이 만든 비공식 앱이고, 각 게임사와 관련이 없어요.
